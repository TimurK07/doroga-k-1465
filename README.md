# Дорога к 1465

Живая карта происхождения казахского народа: от саков до Казахского ханства 1465 года.
Статический сайт — один файл `index.html`, без сборки и зависимостей.

## Локальный запуск
Открыть `index.html` в браузере или:
```
npx serve .
```

## Деплой на Vercel
Вариант 1 — через CLI:
```
npm i -g vercel
vercel          # предпросмотр
vercel --prod   # продакшен
```
Вариант 2 — через GitHub: залить папку в репозиторий → vercel.com → Add New → Project → Import.
Framework Preset: **Other**, Build Command: пусто, Output Directory: `.` (корень).

## Управление на выступлении
- «Запустить историю» — автопроигрывание эпох
- ← → — переключение эпох, пробел — пауза
